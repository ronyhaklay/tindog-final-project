# TinDog — מסמך אפיון מוצר

## מה הבעיה שהמוצר פותר

בישראל אלפי כלבים מחפשים בית — קבוע (אימוץ) או זמני (משפחת אומנה). התהליך הקיים מפוזר בין קבוצות פייסבוק, אתרי עמותות ולוחות מודעות: קשה לחפש, אין פרופיל אחיד לכלב, והאישיות של הכלב "הולכת לאיבוד" בתוך פוסטים ארוכים. במקביל, בעלי כלבים מתקשים למצוא חברים מתאימים לכלב שלהם — כלב אנרגטי צריך חבר אנרגטי, וכלב קטן ומבוגר צריך חברה רגועה.

TinDog פותר את שתי הבעיות עם מנגנון אחד מוכר ומהיר: החלקה (Swipe) בסגנון Tinder. כל כלב מקבל פרופיל שמשווק את האישיות הייחודית שלו — תמונות, גיל, גודל, רמת אנרגיה, אופי וצרכים מיוחדים — והמשתמש מחליק ימינה כדי להתעניין.

## מי המשתמשים של המוצר

1. **מפרסמי כלבים** — בעלים שמוסרים כלב לאימוץ, משפחות שצריכות אומנה זמנית, מתנדבים בעמותות, ובעלי כלבים שמחפשים חברים לכלב שלהם.
2. **מחפשי כלבים** — אנשים שרוצים לאמץ, לשמש משפחת אומנה, או לקבוע פלייטדייט לכלב שלהם.

אותו משתמש יכול להיות בשני הצדדים בו-זמנית (למשל: מפרסם את הכלב שלו לפלייטדייטים וגם מחליק על כלבים לאימוץ שני).

## מי הלקוח

בשלב הראשון המוצר חינמי ופונה לקהל הרחב. לקוחות פוטנציאליים עתידיים:

- **עמותות אימוץ** — פרסום מרוכז של כלבי העמותה וניהול בקשות (מודל מנוי).
- **עסקים לכלבים** (וטרינרים, מאלפים, חנויות) — פרסום ממוקד לקהל בעלי כלבים.

## מטרות עסקיות

1. לקצר את הזמן שכלב ממתין לבית — יותר אימוצים מוצלחים.
2. להעלות את אחוז ההתאמות המוצלחות על ידי חשיפת מידע אישיותי מלא לפני המפגש.
3. לבנות קהילת בעלי כלבים פעילה (פלייטדייטים) שמייצרת שימוש חוזר יומיומי — הבסיס לערך עסקי עתידי.
4. להפוך את חוויית האימוץ לנגישה, מהנה וממכרת כמו אפליקציית היכרויות.

## יכולות תוכנה נדרשות

| יכולת | תיאור |
|---|---|
| הרשמה והתחברות | חשבון משתמש מאובטח (Supabase Auth) |
| ניהול פרופיל אישי | שם, עיר, קצת עליי |
| ניהול פרופילי כלבים | יצירה, עריכה ומחיקה של כלב עם עד 5 תמונות, סוג מודעה (אימוץ / אומנה / פלייטדייט), ופרטי אישיות |
| חפיסת החלקה | הצגת כלבים פעילים שטרם הוחלקו, עם סינון לפי סוג מודעה ועיר |
| בקשות התאמה | החלקה ימינה שולחת בקשה; בעל הכלב מאשר או דוחה |
| צ'אט בזמן אמת | נפתח רק לאחר אישור הבקשה (Supabase Realtime) |
| הרשאות ואבטחה | כל משתמש רואה ועורך רק את מה שמותר לו (RLS) |

## התהליכים המרכזיים במוצר

1. **פרסום כלב**: הרשמה ← הוספת כלב ← העלאת תמונות ← בחירת סוג מודעה ← הכלב מופיע בחפיסה של אחרים.
2. **מציאת כלב**: הרשמה ← סינון החפיסה (אימוץ/אומנה/פלייטדייט, עיר) ← החלקה ימינה ← המתנה לאישור.
3. **אישור והתקשרות**: בעל הכלב רואה את הבקשה עם פרטי המבקש ← מאשר ← נפתח צ'אט ← תיאום מפגש/אימוץ.
4. **ניהול שוטף**: עדכון פרופיל כלב, הסתרת כלב שאומץ (is_active), מעקב אחרי התאמות קיימות.

## מדדי הצלחה (KPIs)

- מספר כלבים מפורסמים פעילים
- אחוז בקשות שמאושרות
- מספר שיחות פעילות (התאמות עם לפחות הודעה אחת)
- זמן ממוצע מפרסום כלב ועד התאמה מאושרת ראשונה
